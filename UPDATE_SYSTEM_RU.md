# Обновление PSразмер PRO — инструкция разработчику

## Как работает обновление

В меню **Программа → Проверить обновления…** пользователь один раз указывает публичную ссылку на папку Яндекс Диска. Программа получает `manifest.json` из этой папки через публичный REST API Яндекс Диска, читает номер версии и список изменений. Также сохраняется поддержка прямой HTTPS-ссылки на `manifest.json`. После подтверждения загружает ZIP, проверяет SHA-256, безопасно распаковывает только каталог `program/`, закрывает приложение, сохраняет резервные копии заменяемых файлов и накладывает новую сборку. При ошибке копирования скрипт пытается восстановить резервную копию.

Локальные данные не входят в пакет обновления и не перезаписываются: `Config`, `Logs`, `Cache`, `History`, `Presets`, `Exports`, `Temp`, `Backups`, `Employees`, `Templates`. Фотографии сотрудников и база SQLite не отправляются на сервер.

## Подготовка выпуска новой версии

1. Обновите `APP_VERSION` в `app/updater.py` и версию установщика в `PSrazmer_PRO.iss`.
2. Соберите новую версию на Windows 10/11 x64: `build_windows.bat`.
3. Создайте пакет, например:

   ```bat
   python make_update_package.py 2.8.2 --notes "Исправления ошибок;Улучшена работа с фотографиями"
   ```

4. Появятся `update_release/PSrazmer_PRO_2.8.2_update.zip` и `update_release/manifest.json`.
5. Загрузите оба файла в один каталог HTTPS-хостинга. URL `manifest.json` укажите пользователям или задайте в их настройках.

Пример manifest:

```json
{
  "version": "2.8.2",
  "package": "PSrazmer_PRO_2.8.2_update.zip",
  "sha256": "64-символьная SHA-256 сумма ZIP",
  "notes": ["Исправления ошибок", "Улучшена работа с фотографиями"]
}
```

`package` может быть относительным именем файла или HTTPS-ссылкой. Обязательно используйте HTTPS. SHA-256 защищает от повреждения/подмены файла при передаче относительно опубликованного манифеста, но сам по себе не заменяет цифровую подпись издателя. Для публичного коммерческого распространения следующим этапом рекомендуется подписывать установщик и обновления Authenticode-сертификатом.

## Ограничения текущей реализации

- Автоматическая установка доступна в собранной Windows-версии (`.exe` из PyInstaller). В режиме запуска исходного Python-кода доступна проверка, но не автоустановка.
- Обновления не удаляют устаревшие файлы, чтобы не затронуть неизвестные пользовательские данные. Если выпуск требует удаления/переименования файлов программы, это нужно отдельно описать в миграции.
- Папка `Templates` намеренно сохраняется. Новые шаблоны для существующих установок распространяйте отдельной миграцией, не перезаписывая пользовательские шаблоны.
- Перед первым публичным выпуском обязательно проверить обновление на отдельном тестовом ПК с Windows и копией базы сотрудников.
