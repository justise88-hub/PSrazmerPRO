# PSразмер PRO 2.8.1 — обновление программы

## Добавлено
- Меню **Программа → Проверить обновления…**.
- Проверка доступной версии по HTTPS-манифесту.
- Показ списка изменений перед установкой.
- Загрузка ZIP-пакета с контролем SHA-256.
- Проверка структуры архива и ограничение размера/числа файлов.
- Установка после закрытия приложения.
- Резервное копирование заменяемых файлов с попыткой отката при ошибке.
- Исключение пользовательских папок из обновления: Config, Logs, Cache, History, Presets, Exports, Temp, Backups, Employees, Templates.
- Скрипт формирования ZIP и manifest.json для публикации обновлений.

## Изменено
- Сборка PyInstaller использует корневую структуру onedir, совпадающую с путями ресурсов и пользовательских данных приложения.
- Версия приложения и установщика повышена до 2.8.1.

## Файлы
- Добавлены: `app/updater.py`, `app/version_utils.py`, `make_update_package.py`, `UPDATE_SYSTEM_RU.md`, `CHANGES_2_8_1_RU.md`.
- Изменены: `app/main.py`, `PSrazmer_PRO.iss`, `build_windows.bat`, `tests/test_core_invariants.py`, `CHANGES_INSTALLER_2_8_RU.md`.

## Проверки
- `py_compile` для изменённых Python-файлов — успешно.
- `unittest` — 3 теста успешно.
- Окно обновления, скачивание с реального HTTPS-сервера и установка на Windows пока не проверялись: в текущей среде нет PySide6 и Windows.
