# Редактор фотографий PSразмер PRO 2.9.0

Вкладка «Фото для HUB»: выберите фото и нажмите «Редактор фото». Доступны поворот на 90°, зеркальное отражение по горизонтали/вертикали, яркость, контраст, насыщенность и резкость. Настройки применяются неразрушающе при экспорте JPG; исходный файл не меняется.

Для автоматической подгонки включите «Автоподгонка лица при подготовке» либо нажмите «Автоподгонка лица» для выбранного снимка. Распознавание выполняется локально с помощью OpenCV, фотографии никуда не отправляются. Если лицо не обнаружено, остаётся ручное кадрирование: перетаскивание изображения, колёсико для масштаба и сброс кадра.

Параметры коррекции хранятся локально в `Config/photo_edits.json`. Для персональных фото используйте надёжную учётную запись Windows и резервное копирование папки данных программы.
