# Безопасность PSrazmer PRO 2.7

## Модель данных
База SQLite локальная. Резервные копии создаются перед изменениями и один раз в день. Проверяется целостность созданной копии. Журнал действий хранится в той же базе, поэтому администратору следует регулярно копировать базу и резервные копии на защищённый носитель.

## Рекомендации Windows
1. Используйте отдельные учётные записи Windows для операторов.
2. Установите NTFS-права на каталоги данных так, чтобы фото, база и резервные копии не были доступны всем пользователям ПК.
3. Включите BitLocker или другое штатное шифрование диска.
4. Не запускайте программу с правами администратора без необходимости.
5. Не храните резервные копии в синхронизируемой общедоступной папке.
6. Проверяйте восстановление резервной копии на отдельном тестовом экземпляре.

## Следующий этап для нескольких рабочих мест
Для нескольких операторов следует перейти на серверную БД с индивидуальной аутентификацией, ролями (оператор/руководитель/администратор), TLS, журналом на сервере, резервированием и блокировкой номеров на серверной стороне. Не следует одновременно открывать одну SQLite-базу через сетевой диск как замену серверу.

## Интеграция Magicard
Пока используется безопасный файловый обмен: создаётся копия `.card`, оригинал не изменяется. У Magicard есть отдельный Magicard SDK для приложений печати и управления принтером (официальная точка получения: https://techs.magicard.com/sdk). Это не означает, что сам HUB предоставляет публичный API. Перед интеграцией необходимо получить SDK и руководство, проверить лицензию и совместимость с Magicard 300/драйвером, затем реализовать адаптер с обработкой ошибок и подтверждением статуса задания. В этой версии SDK не подключён.
