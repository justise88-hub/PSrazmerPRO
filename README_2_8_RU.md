# PSразмер PRO 2.8 — упрощённая навигация

Разработчик: P.Sveshnikov  
Профиль: Magicard 300 / Magicard HUB 2.0.6.

## Что изменено в 2.8
- Реестр «Сотрудники» перенесён на первую вкладку — это начальная точка рабочего процесса выдачи пропуска.
- Порядок разделов: **Сотрудники → Подготовка фото → Magicard HUB → История**.
- В реестре на виду оставлены основные действия: добавить, изменить, удалить, подготовить фото и создать пропуск `.card`.
- Пакетное создание `.card`, открытие HUB, PNG и операции CSV собраны в меню «Дополнительно».
- В подготовке фото на виду оставлены «Подготовить фото» и «Сохранить выбранное». Сохранение всех фото и Excel-каталог перенесены в «Дополнительно».
- Редкие команды не удалены: они доступны через меню, поэтому сохранены все рабочие сценарии.
- История, журнал действий, резервное копирование, автонумерация, кадрирование и экспорт не менялись.

## Проверка
- `app/main.py` прошёл проверку синтаксиса Python (`py_compile`).
- Полный запуск графического интерфейса и проверка кликов требуют Windows с установленными зависимостями PySide6.
- Перед рабочим использованием проверьте запуск на целевом ПК с Magicard HUB 2.0.6. Печать физической карты не тестировалась.

## Состав поставки
Полный проект на базе 2.7; изменения интерфейса сосредоточены в `app/main.py`. Подробный патч: `DIFF_2_7_TO_2_8.patch`. Перечень: `CHANGES_2_8_RU.md`.
