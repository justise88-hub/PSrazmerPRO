# Изменения 2.8.3

- Программа сфокусирована только на сценарии Magicard HUB: сотрудники, портрет для HUB, создание `.card`, история.
- Убраны из интерфейса универсальные размеры фото, экспорт в произвольные форматы и Excel-каталог.
- Удалены дубли значков, старые патчи, архивные инструкции и кэш сборки.
- Упрощены кнопки: основные операции доступны напрямую, редкие операции перенесены в меню «Ещё» и «Обслуживание».
- Добавлена адаптация стартового размера окна под доступную область монитора.
- Минимальный размер окна снижен для небольших экранов; элементы и вкладки переходят в компактный режим.
- Сохранены база сотрудников, автонумерация, резервное копирование, журнал, шаблон `.card` и обновление через Яндекс Диск.

Проверки: синтаксис Python и 3 автоматических теста пройдены. GUI и сборка Windows требуют проверки на реальном Windows-компьютере.


## Версия 2.8.4 — редактор фотографий для Magicard HUB
- Добавлен недеструктивный редактор: поворот на 90°, отражение по горизонтали/вертикали, яркость, контраст, насыщенность и резкость.
- Коррекции применяются при подготовке JPG; исходные фотографии не перезаписываются.
- Настройки коррекции сохраняются локально в Config/photo_edits.json.
- Автоподгонка лица улучшена: расчёт положения и масштаба портрета по найденному лицу.
- Добавлен явный переключатель автоматической подгонки; ручной режим сохраняет перетаскивание, колёсико и кнопки точной настройки.

## 2.8.5 — интеграция с Magicard HUB
- Добавлена предварительная проверка шаблона `.card` перед выпуском карточек.
- Проверяется структура `front/elements`, наличие ровно одного объекта `images.jpg`, корректность встроенных JPEG/PNG data URI.
- Сохранение `.card` выполняется атомарно через временный файл с повторной проверкой JSON и изображений.
- Защита от случайной перезаписи исходного шаблона при одиночном выпуске.
- Пакетный выпуск использует ту же проверку шаблона и атомарное сохранение.
- Добавлен отдельный модуль `app/hub_integration.py` и тесты интеграционного контура.
- Прямое управление HUB/принтером не имитируется: запуск и печать остаются в штатном Magicard HUB.


## 2.9.0 — единый рабочий процесс Magicard HUB
- Добавлено автоматическое обнаружение Magicard HUB в реестре Windows и стандартных каталогах установки; найденный путь сохраняется в настройках.
- Добавлены команды открытия последней карточки `.card` и извлечения встроенного предпросмотра из файла. Открытие использует системную ассоциацию `.card`; печать остаётся в штатном HUB.
- Предпечатная проверка шаблона теперь показывает размеры и форматы обоих встроенных изображений, дополнительно проверяет встроенный preview.
- Добавлена проверка сохранности шаблона: структура, геометрия, тексты и остальные свойства должны совпадать; разрешены изменения только двух фото-payload и встроенного preview.
- Пакетный экспорт больше не перезаписывает существующие `.card` с совпадающими номерами/именами: конфликт попадает в список пропусков.
- Добавлено безопасное восстановление SQLite из резервной копии с проверкой целостности и созданием снимка текущей базы перед заменой.
- Сохранены редактор фото, автоматическое и ручное кадрирование, пакетная обработка, реестр, автонумерация, аудит, история и обновления.
- Интерфейс дополнен действиями «Открыть последнюю .card» и «Предпросмотр .card».

Ограничения проверки: автоматические тесты и синтаксис проверяются в текущей среде; запуск GUI на Windows, фактическая ассоциация `.card`, открытие и печать на Magicard HUB 2.0.6 / Magicard 300 требуют проверки на рабочем Windows-компьютере. Размер фотоокна 21,8 × 29,0 мм остаётся предварительным до физической калибровки в HUB.


## 2.9.1 — исправление сборки Windows

- Исправлен `build_windows.bat`: убран вызов `activate.bat`, который ломал разбор команд `cmd.exe` в среде GitHub Actions.
- Сборка использует Python из `PATH`, создаёт `.venv` и вызывает интерпретатор виртуального окружения напрямую.
- Убраны вложенные блочные конструкции BAT, чтобы избежать ошибки `was unexpected at this time`.
- Добавлены отдельные понятные сообщения при отсутствии Python и при ошибке сборки.
- Функциональность программы и формат `.card` не менялись.
