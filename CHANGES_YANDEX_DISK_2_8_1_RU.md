# Изменения: обновления через Яндекс Диск

- Клиент обновления принимает публичную ссылку на папку Яндекс Диска.
- `manifest.json` запрашивается через `cloud-api.yandex.net/v1/disk/public/resources/download`.
- ZIP обновления разрешается по имени файла внутри той же публичной папки.
- Сохранена совместимость с прямой HTTPS-ссылкой на `manifest.json`.
- Ссылка на источник обновлений хранится в настройках как `update_source_url`; старый ключ `update_manifest_url` читается для совместимости.
- Обновлены подсказки в окне обновления и инструкция по выпуску релизов.
- Пользовательские данные не включаются в обновление и не отправляются на Яндекс Диск.
