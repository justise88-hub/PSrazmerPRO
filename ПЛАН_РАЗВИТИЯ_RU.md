# PSразмер PRO 2.3 — план и статус

## Целевая конфигурация
- Magicard 300 + Magicard HUB 2.0.6.
- Карта CR80: 85,60 × 53,98 мм.
- По скриншоту редактора область фото: примерно 21,8 × 29,0 мм, 300 DPI.

## Реализовано в проекте
- Подготовка фото, кадрирование, пакетная обработка, автопоиск лица через OpenCV.
- Профиль Внуково 21,8 × 29,0 мм / 300 DPI / JPG (оценка по скриншоту).
- SQLite-реестр сотрудников, CSV импорт/экспорт.
- CSV-пакет с локальными фотографиями и PhotoFile.
- Запуск HUB и открытие Проводника с выбранным JPG.
- Предварительный PNG-макет CR80, история, логи и резервирование.

## Что видно на скриншоте
Редактор дизайна карты, тип CR80, список Image/Text, вкладки Elements/Data, портрет справа сверху. Это не окно записи сотрудника и не окно свойств фотографии.

## Следующие шаги для полной автоматизации
1. В HUB выделить верхний правый объект Image и открыть его свойства. Нужны Width, Height, X, Y и режим заполнения/обрезки.
2. Открыть вкладку Data и показать доступные поля для привязки к элементам Text и Image.
3. Проверить импорт CSV: есть ли тип Image/Photo и можно ли сопоставить его со столбцом пути к JPG.
4. Если HUB поддерживает привязку фото по пути — реализовать экспорт в точном формате.
5. Если нет — проверить UI Automation по реальным AutomationId/Name; не применять ненадёжные клики по координатам.
6. Проверить CR80 и пробную печать на Magicard 300.
7. Собрать EXE на Windows 10/11 и проверить на чистой системе.

## Пока не подтверждено
Публичный API/CLI для создания карточки, автопривязка фото через PhotoFile, точные физические размеры Image. До проверки эти функции не заявляются как готовые.
