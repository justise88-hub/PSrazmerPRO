# Подготовка установщика Windows — PSразмер PRO 2.8

## Добавлено
- `PSrazmer_PRO.iss` — сценарий установщика Inno Setup 6 на русском языке.
- `build_installer.bat` — сборка `PSrazmer_PRO_2_8_Setup.exe`.
- `INSTALL_WINDOWS_RU.md` — пошаговая инструкция установки и сборки.
- Обновлён `build_windows.bat`: сборка PyInstaller в режиме onedir, с ресурсами, шаблоном HUB, PySide6 и OpenCV.

## Установка и сохранность данных
- Установка без прав администратора в `%LOCALAPPDATA%\Programs\PSразмер PRO`.
- Ярлык в меню «Пуск», дополнительная опция ярлыка рабочего стола.
- Пользовательские данные `Employees`, `Config`, `Exports`, `Backups`, `Logs`, `History` при удалении программы намеренно сохраняются.
- Magicard HUB 2.0.6 и драйвер Magicard 300 устанавливаются отдельно.

## Ограничения текущей сборки
Этот архив содержит исходный проект и сценарии для создания Windows Setup. Сам `Setup.exe` должен быть собран на Windows 10/11 x64 с Python 3.11/3.12 и Inno Setup 6; в текущей среде нельзя достоверно собрать и проверить Windows-установщик. Не выдаём непроверенный бинарный файл за готовый установщик.

## Обновление приложения
- Добавлено меню «Программа → Проверить обновления…».
- Проверка HTTPS-манифеста, скачивание ZIP, SHA-256 контроль, безопасная распаковка и резервирование заменяемых файлов перед установкой.
- Пользовательские данные и папка шаблонов исключены из обновления.
- Добавлены `make_update_package.py` и `UPDATE_SYSTEM_RU.md` для подготовки и публикации обновлений.
- PyInstaller собирает onedir-пакет в корневую структуру, соответствующую путям данных приложения.
