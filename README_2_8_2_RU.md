# PSразмер PRO 2.8.2

Фирменное обновление интерфейса в графитово-жёлтой палитре.

## Визуальные изменения
- Графитовый интерфейс и тёплые жёлтые акценты.
- Переработаны кнопки, вкладки, таблицы, поля ввода, меню, подсказки и полосы прокрутки.
- Новая заставка запуска.
- Новый значок приложения и согласованный набор пиктограмм.
- Разработчик: P.Sveshnikov.

## Сборка Windows
1. Установите Python 3.11/3.12 x64.
2. Запустите `build_windows.bat`.
3. После успешной сборки запустите `build_installer.bat` (требуется Inno Setup 6).

Пользовательская база, фотографии и шаблон Magicard HUB не изменялись.


## Обновления через Яндекс Диск

Источник обновлений разработчика уже прописан в программе: https://disk.yandex.ru/d/3-8I5L5VUQpoEA. Откройте `Программа → Проверить обновления…` и нажмите `Проверить обновления`. Для обнаружения выпуска в публичной папке должны находиться `manifest.json` и ZIP-пакет соответствующей версии. Если папка ещё пуста или файлы не опубликованы, программа сообщит об ошибке/отсутствии манифеста.
