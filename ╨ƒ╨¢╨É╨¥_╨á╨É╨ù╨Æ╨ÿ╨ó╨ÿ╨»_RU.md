# План развития — PSразмер PRO 2.6

| Функция | Статус |
|---|---|
| Замена только фотографии в .card | Реализовано; сохранение прочих элементов по структуре JSON |
| Перемещение/масштабирование портрета | Реализовано в одиночном редакторе |
| Предпросмотр всей карты | Реализовано перед сохранением |
| Пакетная подготовка сотрудников | Реализовано для выделенных строк; пропуск записей без фото |
| Автопоиск лица | Реализовано при наличии OpenCV; требуется проверка на реальных фото |
| Автонумерация и предыдущий номер | Реализовано; показаны предыдущий и следующий номера |
| Защита от повторных номеров | Реализовано при добавлении/редактировании |
| Дата выдачи в реестре/CSV | Реализовано; текст шаблона не меняется по требованию пользователя |
| История созданных .card | Реализовано в SQLite |
| Резервные копии базы | Реализовано: автоматические и ручные, хранить до 30 |
| Быстрый запуск .card/HUB | Реализовано через файловую ассоциацию и кнопку запуска HUB |
| Прямая передача фото в активную запись HUB | Не подтверждена; не автоматизировать через координатные клики без API/AutomationId |
| Сборка и печать на Windows | Требуется финальная проверка на целевом ПК |

**Критическое требование:** пользователь уточнил, что в шаблоне необходимо заменить только старую фотографию. Все надписи, номера, даты, логотипы, цвета и геометрия сохраняются.
