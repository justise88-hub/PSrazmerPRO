Иконки PSразмер изображений PRO

PSrazmer.ico — главный значок приложения, используется в заголовке окна, EXE и ярлыках.
Settings.ico — настройки.
History.ico — история.
Security.ico — безопасность.
About.ico — информация о программе.
Cleanup.ico — очистка временных файлов.
Help.ico — справка.
Logs.ico — журнал ошибок.

После сборки через build_windows.bat запустите create_shortcuts.ps1 из папки dist\PSrazmer_PRO.
Скрипт создаёт ярлыки на рабочем столе и в меню Пуск с правильным значком.
