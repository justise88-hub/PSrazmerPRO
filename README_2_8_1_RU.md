# PSразмер PRO 2.8.1

В версии добавлено окно обновления: **Программа → Проверить обновления…**.

## Для пользователя

1. Установите сборку программы обычным способом.
2. Получите у разработчика HTTPS-адрес `manifest.json`.
3. Откройте меню **Программа → Проверить обновления…**.
4. Вставьте адрес манифеста и нажмите **Проверить обновления**.
5. Если новая версия доступна, просмотрите список изменений и нажмите **Скачать и установить**.
6. Подтвердите установку. Программа закроется, обновится и запустится снова.

Обновление не отправляет фотографии, данные сотрудников, базу SQLite или настройки на сервер. Локальные папки данных и шаблоны не перезаписываются. Перед заменой файлов программы создаётся резервная копия.

## Важно

На данный момент адрес сервера обновлений не предустановлен. До публикации разработчиком HTTPS-манифеста проверка обновлений работать не будет. Подробная инструкция по подготовке и публикации выпусков находится в `UPDATE_SYSTEM_RU.md`.


## Обновления через Яндекс Диск

См. `UPDATE_YANDEX_DISK_RU.md`: настройка публичной папки, публикация `manifest.json` и ZIP, обновление клиентских компьютеров.
