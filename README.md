# PSразмер PRO 2.6 — Внуково / Magicard HUB

**Разработчик: P.Sveshnikov**

## Совместимость и профиль
- Windows 10/11.
- Magicard HUB 2.0.6; принтер Magicard 300.
- Шаблон: `Templates/New Card Design.card` (пользовательский файл).
- Размер портретного файла: 21,8 × 29,0 мм, JPG, 300 DPI. Размер области фото взят из оценки прежнего скриншота и должен быть сверён с настройками объекта Image в HUB.

## Главное в версии 2.6
1. **Замена только фотографии в шаблоне .card.** Надписи, номера, даты, логотипы, цвета, геометрия и остальные объекты не меняются. Обновляются встроенные варианты изображения `base64image`, `originalBase64Image` и миниатюра `about.preview`.
2. **Редактор портрета.** Перемещение мышью и стрелками, масштаб колёсиком, сброс кадрирования. При одиночной подготовке можно проверить положение лица вручную.
3. **Предпросмотр всей карты** с новой фотографией перед сохранением .card.
4. **Пакетная подготовка .card.** Выделите несколько сотрудников в таблице (Ctrl/Shift) и нажмите «Пакет .card». Для каждого сотрудника создаётся отдельная копия шаблона; автоопределение лица применяется при наличии OpenCV.
5. **Автонумерация и защита от дублей.** Следующий номер вычисляется по существующим номерам и сохранённому последнему значению. Повтор номера блокируется при добавлении/редактировании. Над таблицей показаны предыдущий и следующий номера.
6. **Дата выдачи.** Сохраняется в реестре сотрудника и CSV. В соответствии с вашим уточнением дата и другие надписи самого шаблона не заменяются — меняется только фото.
7. **История карточек.** Вкладка истории показывает последние созданные .card с датой, ФИО, номером и путём.
8. **Резервные копии базы.** Автоматически перед изменениями реестра; вручную — кнопкой на вкладке истории. Хранится до 30 последних копий в `Backups`.
9. **Быстрый запуск.** После одиночного создания .card Windows пытается открыть готовый файл через зарегистрированное приложение; при неудаче открывает его расположение. Magicard HUB можно также запустить кнопкой из вкладки HUB.
10. Разработчик указан как **P.Sveshnikov**.

## Рабочий процесс: один пропуск
1. Откройте «Сотрудники Внуково», выберите запись или добавьте новую.
2. Убедитесь, что выбран правильный номер и фотография.
3. Нажмите «Создать пропуск (.card)».
4. В редакторе переместите/масштабируйте фото и сохраните кадрирование.
5. Проверьте полноразмерный предпросмотр карты.
6. Сохраните отдельный .card и откройте его в Magicard HUB.

## Пакетная подготовка
1. Выделите сотрудников в таблице с Ctrl/Shift.
2. Нажмите «Пакет .card» и укажите папку вывода.
3. Программа пропустит записи без доступной фотографии, создаст индивидуальные .card для остальных и запишет их в историю.
4. Проверьте каждый файл в HUB до печати.

## Важные ограничения интеграции
- Файл `.card` — JSON-контейнер, и в предоставленном шаблоне обнаружен ровно один портретный объект `images.jpg`. Программа меняет только данные этого изображения и встроенный предпросмотр.
- Публичный/подтверждённый API или CLI Magicard HUB для прямого импорта фото в активную карточку не установлен. Поэтому программа не имитирует ненадёжные клики по координатам и не заявляет, что выполняет бесшовную запись в закрытую базу HUB. Вместо этого готовит корректную копию .card, которую открывает сам HUB.
- При пакетной подготовке применяется автоцентрирование/автопоиск лица; ручная подстройка предусмотрена в одиночном редакторе.
- Перед серийной печатью обязательно откройте тестовый .card в вашей версии HUB 2.0.6 и выполните пробную печать на Magicard 300.

## Данные и безопасность
Все данные сотрудников и фотографии хранятся локально. База: `Employees/employees.sqlite3`; настройки: `Config`; готовые файлы: `Exports`; резервные копии: `Backups`; журнал: `Logs`. Не удаляйте эти папки, если нужны ваши данные.

## Запуск и сборка
- Запуск из исходников: `run_windows.bat`.
- Сборка автономной папки EXE: `build_windows.bat` (Windows 10/11, Python 3, доступ к PyPI при первой установке зависимостей).
- Зависимости перечислены в `requirements.txt`.

## Проверки в этой поставке
- Проверен синтаксис Python (`py_compile`).
- Проверен JSON предоставленного .card, уникальность портретного объекта и декодирование встроенных изображений.
- Проверено, что шаблон входит в архив.
- GUI и открытие/печать в Magicard HUB нельзя подтвердить в текущей среде: здесь нет PySide6, Windows и установленного HUB. Нужна пробная проверка на целевом ПК.
