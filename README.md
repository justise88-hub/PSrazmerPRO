# PSразмер изображений PRO 2.3 — Внуково / Magicard 300

## Конфигурация
- Принтер: Magicard 300.
- Программа: Magicard HUB 2.0.6.
- Тип карты в редакторе HUB на скриншоте: CR80, 85,60 × 53,98 мм.
- Разрешение печати: 300 × 300 dpi.
- По скриншоту дизайна область портрета оценена в **21,8 × 29,0 мм (ширина × высота)**.
- Экспорт портрета: JPG, 300 DPI, примерно 258 × 343 пикселя.

**Важно:** размер 21,8 × 29,0 мм измерен пропорционально по скриншоту редактора. Это оценка, а не официальная спецификация Magicard и не точные координаты из файла дизайна. Перед серийной печатью выделите объект Image в HUB и проверьте его Width/Height/Position в свойствах элемента.

## Установка
1. Распаковать ZIP в отдельную папку Windows 10/11.
2. Запустить `run_windows.bat`.
3. Для сборки EXE на Windows запустить `build_windows.bat`.
4. На вкладке Magicard HUB выбрать путь к исполняемому файлу HUB 2.0.6.

## Рабочий процесс
1. Добавить сотрудника во вкладке «Сотрудники Внуково» и указать исходное фото.
2. Нажать «Подготовить фото»: программа определит лицо (если OpenCV установлен), обрежет портрет в пропорции рамки и сохранит JPG 300 DPI.
3. Нажать «Открыть HUB с фото»: HUB запускается, а готовый файл выделяется в Проводнике.
4. В HUB открыть нужный дизайн/запись и добавить JPG штатной командой.
5. Проверить Print Preview и выполнить пробную печать одной карты.

## Что подтверждает присланный скриншот HUB
- Открыт редактор дизайна `New Card Design.cardШАБЛОН (Saved)`.
- Выбран формат CR80.
- Слева видна панель Elements с объектами Image и Text.
- Доступна вкладка Data.
- На макете портрет находится справа сверху.
- Скриншот не показывает свойства выделенного Image, содержимое Data или мастер импорта; точные размеры объекта и способ автоматической привязки фото пока не подтверждены.

## Интеграция
Реализованы локальная подготовка изображения, запуск HUB, выделение готового JPG, база сотрудников SQLite, CSV и CSV-пакет с колонкой PhotoFile. Прямое прикрепление фото в карточку не имитируется: нужно проверить свойства Image/Data в HUB 2.0.6 или получить документированный интерфейс/API Magicard.

## Персональные данные
База сотрудников и фотографии хранятся локально. Не удаляйте папки `Employees`, `Exports`, `Config`, `History`, `Backups`, если нужны данные и история.

## Проверки
Проверяется синтаксис Python и создание JPG требуемого размера. GUI, EXE на Windows, HUB 2.0.6 и физическая печать требуют отдельного теста на целевом компьютере.
