# PSразмер PRO 2.9.1 — Magicard HUB

Специализированная Windows-программа для подготовки пропусков под **Magicard HUB 2.0.6** и профиль принтера **Magicard 300**. Универсальные форматы фото и лишние инструменты убраны из интерфейса.

## Основной процесс
1. Добавьте сотрудника, заполните данные и выберите исходную фотографию.
2. Подготовьте портрет: кадрирование мышью, масштаб колёсиком, автоматическое определение лица.
3. Создайте отдельную копию карточки `.card` на основе шаблона HUB.
4. Откройте файл в Magicard HUB, проверьте макет и печатайте штатной командой HUB.

## Рабочий профиль
- Карта: CR80, 85,60 × 53,98 мм.
- Фото: JPG, 300 DPI, окно 21,8 × 29,0 мм (оценка по предоставленному скриншоту; до тиража сверить размеры и позицию Image в HUB).
- Пользовательские данные хранятся локально: `Employees`, `Config`, `History`, `Backups`, `Exports`.
- Обновления: публичная папка Яндекс Диска, настроенная в программе.

## Адаптация экрана
Qt High-DPI поддерживает системный масштаб Windows; стартовый размер окна рассчитывается по доступной области текущего монитора. Макет построен на растягиваемых компоновках, а на узких окнах элементы переходят в компактный режим.

## Сборка Windows
1. Установите Python 3.11/3.12 x64.
2. Запустите `build_windows.bat`.
3. Установите Inno Setup 6 и запустите `build_installer.bat`.

Magicard HUB и драйвер принтера устанавливаются отдельно. Прямое управление печатью не заявляется: печать выполняется в Magicard HUB.

### Быстрый сценарий 2.9.1
1. Откройте реестр и добавьте сотрудника с фотографией.
2. Подготовьте портрет: используйте автоподгонку лица или ручное кадрирование и редактор.
3. Проверьте шаблон во вкладке Magicard HUB.
4. Создайте персональную копию `.card`; исходный шаблон не меняется.
5. Используйте «Открыть последнюю .card» или откройте файл в HUB вручную.
6. Проверьте макет и выполните печать штатными средствами Magicard HUB.

Вкладка истории содержит последние выпуски и аудит. В меню «Обслуживание» доступны создание и восстановление резервной копии.
