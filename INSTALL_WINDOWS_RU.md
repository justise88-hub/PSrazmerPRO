# Установка PSразмер PRO 2.8 в Windows

## Для пользователя
После сборки разработчиком запустите `PSrazmer_PRO_2_8_Setup.exe`, нажмите «Далее» и завершите установку. Установщик создаёт ярлык в меню «Пуск»; ярлык на рабочем столе можно включить в дополнительных параметрах. Для установки не нужны права администратора.

## Сборка установщика на Windows 10/11 x64
1. Установите Python 3.11 или 3.12 x64 и отметьте добавление Python в PATH.
2. Установите Inno Setup 6 (https://jrsoftware.org/isinfo.php).
3. Распакуйте весь архив в обычную папку, например `C:\Build\PSrazmer_PRO`.
4. Запустите `build_windows.bat`. Скрипт создаст виртуальное окружение, установит зависимости и соберёт приложение в `dist\PSrazmer_PRO`.
5. Запустите `build_installer.bat`. Готовый установщик появится в `installer_output\PSrazmer_PRO_2_8_Setup.exe`.

## Данные и обновление
Программа хранит рабочие данные рядом с EXE. Поэтому установщик размещает приложение в `%LOCALAPPDATA%\Programs\PSразмер PRO`, где у обычного пользователя есть права записи. При удалении программы пользовательские каталоги с базой сотрудников, настройками, фотографиями, экспортами и резервными копиями намеренно не удаляются. Перед обновлением всё равно рекомендуется создать резервную копию через программу.

## Требования
Windows 10/11 x64. Magicard HUB 2.0.6 устанавливается отдельно. Для печати нужен установленный драйвер Magicard 300.
